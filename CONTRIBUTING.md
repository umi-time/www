# Contributing to the Umi‑Time Website

This repository contains the documentation site, demos, and interactive visualizations for Umi‑Time.  
It is built with **Astro** and licensed under **MIT**.

---

## Getting Started

Clone the repository and install dependencies using a clean lockfile installation:

```bash
git clone https://github.com/umi-time/www.git
cd www
npm ci
```

Start the development server:

```bash
npm run dev
```

Build the site:

```bash
npm run build
```

---

## Types of Contributions

You may contribute by:
- Improving documentation pages  
- Fixing layout or styling issues  
- Enhancing interactive demos (map, clock, solar visualizations)  
- Adding examples or tutorials  
- Improving accessibility or performance  

---

## Development Guidelines

- Use Astro components for page structure  
- Keep demos self‑contained and readable  
- Prefer pure functions for solar calculations  
- Ensure mobile and desktop compatibility  
- Follow existing CSS and component conventions  
- Keep content aligned with the Umi‑Time Standard  

---

## Pull Requests

Before submitting a PR:
- Ensure the site builds successfully without compilation errors
- Test demos locally in both development and production modes  
- Verify layout responsiveness and basic accessibility standards
- Update documentation if needed  
- Reference related issues  

---

## Issues

When reporting a problem, please include:
- Page URL  
- Browser and OS  
- Steps to reproduce  
- Screenshots if helpful
